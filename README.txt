MY PRINCESS SURPRISE WEBSITE

1. Extract the ZIP file.
2. Open the folder in Visual Studio Code.
3. Open index.html in your browser (or use the Live Server extension).
4. The website is mobile-friendly and works on iPhone Safari.

PUBLISH IT SO THE QR CODE CAN OPEN IT:
1. Create a new public repository on GitHub, for example: my-princess-surprise
2. Upload index.html, style.css, and script.js to the repository root.
3. In GitHub, open Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select main and / (root), then Save.
6. Wait for GitHub Pages to publish. Your website URL will look like:
   https://YOUR-USERNAME.github.io/my-princess-surprise/

QR CODE:
A working QR code needs the final published website URL. After GitHub Pages gives you the link, send it to me and I can make the QR code for you.

PERSONALIZATION:
The website uses only “My Princess” and does not include your real name.
